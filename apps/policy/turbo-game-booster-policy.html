1. Overview

Turbo Game Booster is a dedicated game library, launcher, and system monitor application designed to help users organize installed games, launch them with tactical focus protocols, and view real-time device hardware metrics. The app does not require account creation, registration, or login. All user preferences and game library configurations are stored strictly on the local device.

2. Information Stored on Your Device

The app stores the following data locally on your device to maintain your customized settings:

  • Saved game library: Package names and display labels of games explicitly added by the user.
  • Visual theme preferences: Dark, Light, or System default appearance selection.
  • Accent color: The chosen cyber theme color.
  • Haptic feedback preference: User choice for tactile button feedback.
  • Floating HUD preferences: User-configured screen position, size scale, opacity, color, and metric visibility toggles.
  • Gaming Focus protocols: User opt-in settings for Focus Mode (Do Not Disturb) and Screen Brightness Lock.

This data is stored purely locally in Android private app storage and is never uploaded to any remote server or cloud database.

3. Information Accessed by the App

To deliver real-time metrics and launcher features, Turbo Game Booster accesses the following device status information:

  • Installed apps: Package names and labels used to display launchable games in your library.
  • Battery status & temperature: Device battery percentage, charging state, and temperature as reported by Android battery APIs.
  • CPU usage: Estimated real-time processor load percentage.
  • RAM usage: System memory metrics (used, available, and total memory) provided by Android ActivityManager.
  • Network connectivity: State of Wi-Fi or mobile data connectivity.
  • Network latency (Ping): Real-time response time measured by opening lightweight socket requests to public DNS resolvers (such as 8.8.8.8 and 1.1.1.1 over port 53).
  • Wi-Fi connection info: Frequency band (2.4 GHz / 5 GHz) and link speed where accessible.
  • Display specifications: Screen resolution, refresh rate (Hz), density, and graphical capabilities (OpenGL / Vulkan).
  • Sensor capabilities: Presence of hardware sensors (gyroscope, accelerometer, vibrator).

This information is processed on-device in real-time solely to present hardware stats to the user. It is never logged, stored remotely, or transmitted.

4. Permissions and Their Purposes

Turbo Game Booster uses only the permissions necessary to provide its core features:

  • INTERNET: Allows socket requests to public DNS servers to measure live network latency (ping) in milliseconds.
  • ACCESS_NETWORK_STATE: Allows checking whether Wi-Fi or mobile cellular data is active.
  • ACCESS_WIFI_STATE: Reads connection frequency and link speed where supported by the device.
  • SYSTEM_ALERT_WINDOW (Display over other apps): Required for the optional Floating Performance HUD to appear over active gameplay. This permission must be explicitly granted by the user via Android System Settings.
  • FOREGROUND_SERVICE & FOREGROUND_SERVICE_SPECIAL_USE: Keeps the user-initiated Floating HUD actively running over games and maintains a persistent system notification so the user can see its status and stop the overlay at any time.
  • POST_NOTIFICATIONS: Required on Android 13 (API level 33) and above exclusively to display the active status and "Stop" control notification for the Floating HUD. The app does not send marketing, advertising, or spam notifications.
  • ACCESS_NOTIFICATION_POLICY (Do Not Disturb Access): Used solely for the optional "Focus Mode" protocol, which silences incoming notifications during gaming sessions to prevent interruptions. The user must explicitly grant Do Not Disturb access in System Settings.
  • WRITE_SETTINGS (Modify System Settings): Used solely for the optional "Brightness Lock" protocol, which maintains screen brightness during gameplay. The user must explicitly grant permission in System Settings.

5. Data Collection, Sharing, and Advertising

  • Zero Data Collection: We do not collect, transmit, store on servers, or sell any personal information, device identifiers (such as IMEI or Android ID), location data, or usage logs.
  • No Third-Party Trackers: The app contains no third-party advertising SDKs, behavioral trackers, or analytics platforms.
  • Network Interactions: External network communication is strictly confined to socket latency checks to public DNS servers as described above.

6. The Boost Performance Feature

The Boost Performance feature triggers standard Java Virtual Machine (JVM) garbage collection and memory cache reclamation within the app's own process. Turbo Game Booster makes no deceptive claims and does not guarantee:

  • Force-closing or terminating background processes of other third-party applications.
  • Overclocking hardware CPU or GPU frequencies.
  • Altering system kernel parameters or bypassing OS thermal throttling.
  • Guaranteed increases in game frame rates (FPS) or elimination of network latency.

The feature operates strictly within non-root Android system boundaries as a convenience utility.
