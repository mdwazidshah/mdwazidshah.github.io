1. Overview

Turbo Game Booster is a game library and launcher app that helps users organize their installed games, launch them, and view supported device information.

The app does not require users to create an account. According to the app's current implementation, its preferences and saved game library are stored locally on the device.

2. Information Stored on Your Device

The app stores the following information locally to provide its features:

  • Saved game library: App names and package names of games added by the user.
  • Theme preference: Dark, Light, or System theme selection.
  • Accent color: The selected app appearance color.
  • Haptic feedback preference: The user's selected feedback setting, if applicable.
  • Floating HUD preferences: Position, size, opacity, color, and selected display options.

This information is used to maintain the user's preferences and app functionality.

3. Information Accessed by the App

Depending on the features used and device capabilities, Turbo Game Booster may access the following information:

  • Installed apps: App names and package names used to display apps that users can add to their game library.
  • Battery temperature: Displayed where the device provides this information.
  • CPU usage: Displayed where supported by the app and device.
  • RAM usage: Displayed as supported by the device and Android version.
  • Network connectivity: Used to check whether a network connection is available.
  • Network latency: The app may send network requests to public DNS servers, including 8.8.8.8 and 1.1.1.1, over port 53 to estimate network response time.
  • Wi-Fi information: Wi-Fi frequency and link speed, where available and accessible.
  • Device information: Available hardware, display, memory, battery, sensor, and build information.
  • Screen refresh rate: Displayed where supported by the device.

The information listed above is accessed to provide the corresponding app features. Network requests used for latency measurements communicate with external DNS servers. Network operators or service providers may process connection information according to their own practices.

4. Permissions and Their Purposes

  • INTERNET: Allows the app to make network requests for network latency measurements.
  • ACCESS_NETWORK_STATE: Allows the app to check network connectivity status.
  • ACCESS_WIFI_STATE: Allows the app to access available Wi-Fi connection information, such as frequency and link speed, where supported.
  • SYSTEM_ALERT_WINDOW — Display over other apps: Allows the optional Floating HUD to appear over other apps, including games. Users must grant this permission through Android Settings. The overlay can be used only when enabled by the user.

The app's available functionality may vary depending on Android version, device manufacturer, system restrictions, and granted permissions.

5. Data Collection, Sharing, and Advertising

The app is designed to store its saved game library and preferences locally on the device.

The developer's current implementation is intended not to transmit this locally stored information to the developer's servers or upload it to a developer-operated cloud service.

The app is not intended to collect personal information for advertising or analytics. Any statement about third-party SDKs, advertising, analytics, crash reporting, or other data transmission must reflect the actual libraries and services included in the published app.

Network latency measurements may communicate with external DNS servers, as described above.

6. The Boost Now Feature

The Boost Now feature requests Java Virtual Machine (JVM) garbage collection within the app's runtime.

This request may help reclaim unused memory associated with the app itself. Its effect depends on the runtime and device.

Turbo Game Booster does not claim that this operation:

  • Kills other apps or processes.
  • Increases CPU or GPU clock speeds.
  • Changes system-level performance settings.
  • Guarantees higher game frame rates.
  • Guarantees lower network latency or reduced game lag.

No specific performance improvement is guaranteed.
